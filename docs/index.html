AI SaaS Localization Assistant

Free localization quality checker + AI JSON translation workbench + professional human translation lead capture. Two independent products, one account system.

免费本地化质量检测 + AI JSON 翻译工作台 + 母语级人工翻译需求承接。两条业务线彼此独立，共用一套账号与 AI 服务。

These are real screenshots captured from the running app (Node 22 / Express / SQLite, 46 automated tests). The interactive app is a Node service and cannot run on GitHub Pages — this page is the static design review. Translations shown with ［DE］／［FR］ prefixes are mock-engine output: the app runs offline until a model key is configured.
